# Проверка безопасности

13.11.2026: итоговый демонстрационный образ Caddy 2.11.9-alpine (Alpine 3.24.4) проверен Trivy 0.76.2, база загружена в день проверки. Уязвимостей HIGH/CRITICAL в пакетах Alpine нет. Базовый Caddy 2.11.2 заменён после сканирования.

Остаются две HIGH-записи в Go-зависимостях Caddy. Они не скрыты глобальным ignore; перед публичным выпуском требуется повторная проверка и обновление образа. В текущей конфигурации оценены как не имеющие пути эксплуатации через сайт:

Первичные описания: [go-jose advisory](https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q), [Go vulnerability GO-2026-6860](https://pkg.go.dev/vuln/GO-2026-6860). Оценка относится только к приложенной конфигурации; при её изменении исключения пересмотреть. Это документированные временные исключения, а не утверждение об отсутствии всех уязвимостей.

`npm audit --audit-level=high` не обнаружил HIGH/CRITICAL. Moderate-записи minimatch в цепочке ESLint/typescript-eslint относятся к инструментам разработки; исходные glob-шаблоны локальные, посетители их не передают. Срок проверки обновлений — 20.11.2026. Node/npm/инструменты не включены в финальный образ.

Повторная проверка:

```sh
npm audit --audit-level=high
trivy image --scanners vuln --severity HIGH,CRITICAL IMAGE
```

Не исключайте новые CVE автоматически. Пароли и токены не хранить в контенте или публичных env. Контейнер использует непривилегированные порты и UID 10001, `cap_drop: ALL`, no-new-privileges и read-only; file capability Caddy удаляется при сборке, иначе бинарник не запускается с пустым набором capabilities. Томам Caddy нужны права UID/GID 10001. CSP разрешает только точный hash встроенного JSON-LD и ресурсы своего origin.
